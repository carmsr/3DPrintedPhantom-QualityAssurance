# 3D-printed phantom Quality Assurance Package

In this repository you will find all the necessary material to reproduce the Quality Assurance analysis for PET/CT and PET/MR imaging systems with the 3D-printed phantom: 
- Phantom printing models: **STL models** folder
- Original image analysis code in Python: **Python code** folder
- Adaptation of the analysis code to the 3D-Slicer plugin: **3D-Slicer plugin** folder
